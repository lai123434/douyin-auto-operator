# 抖音网页版界面结构与语义定位（实证版）

> 基于真实全流程执行的实测（刷流、登录、详情、分享面板、私信）。抖音前端 class 不稳定，**一律以可见文本语义定位**；图标类按钮（分享/转发/发送）无文字，需截图定位或用弹层视图。以下供 `bu.find()` / 快照识别。

## 1. 顶部主导航（header）
- 内容分区：`精选`、`推荐`、`AI抖音`、`关注`、`朋友`、`我的`、`直播`、`放映厅`、`短剧`、`小游戏`
- 右侧：搜索框（placeholder“搜索你感兴趣的内容”）、`搜索`、`充钻石`、`投稿`、`登录`
- 首页重定向 `/jingxuan`（精选）或 `/`（推荐）。登录后顶栏出现“关注 N”（关注数）、无“登录”按钮。

## 2. 内容分类 tab
推荐流上方：`全部 公开课 游戏 二次元 音乐 影视 美食 知识 小剧场 生活vlog 体育 旅行 亲子 动物 三农 汽车 美妆穿搭`。点击切换垂类。

## 3. 视频卡片（推荐流主体）
字段：**标题**（含 `#话题`）、**作者**（`@ 用户名 · 时间`）、**时长**（`04:05`/`45:08`）、**热度**（`14.0万`/`4539`）、长描述（可选）。
提取：`snapshot(within="viewport", view="interactive")` + `scroll(direction="down")` 加载更多。

## 4. 登录闸口与会话（实证）
- **刷流无需登录**；点击视频卡片进详情会弹“登录后免费畅享高清视频 / 扫码登录” → 认证阻塞 → `interaction.request_action` 请扫码。
- 登录方式：`扫码登录`（需 APP 扫一扫）、`验证码登录`、`密码登录`。
- **登录会话脆弱**：登录后再 `navigate`/刷新 `www.douyin.com` 可能掉线、重弹“一键登录/登录其他账号”。登录后**避免无谓导航刷新**。
- 顶栏出现“登录”按钮或弹“一键登录” = 会话已掉线，需重新扫码。

## 5. 浏览器视口不可用（实证）
登录/用户接管后自动化窗口可能被最小化/折叠 → `snapshot` 报 `AhaBUA snapshot failed`、`screenshot` 报“viewport unavailable”，`page_info` 显示 `w:0 h:0`。
处理：`bu.resync()` → 重试；仍失败 → `interaction.request_action` 请用户恢复窗口到前台并展开，交回后 `resync()`。

## 6. 视频详情页
- 全屏播放时右侧操作栏可能隐藏 → 用弹层视图（`/jingxuan?modal_id=<id>`）更稳，或滚动露出。
- 互动数据：❤️点赞 / 💬评论 / ⭐收藏 / **↪️转发**，均为**图标**（无文字）。转发图标位于右侧操作栏（弹层视图约 (897,500)）。
- `find("分享|转发")` 常匹配不到（图标），需截图定位或用弹层视图点转发图标。

## 7. 分享面板
打开方式：点转发图标。
- **搜索框**：`find("搜索")` 或快照 textbox（实测 ref 形如 n1478/n869），输入**精确昵称**（大小写敏感）。
- 好友条目旁有“分享”按钮、“捎句话”（发消息入口）。
- **只列出/搜到与你互关的好友**。非互关（对方仅关注你）搜不到、无法转发；可用“捎句话/私信”。
- “复制链接”按钮 → 剪贴板取 `https://v.douyin.com/...` 短链。
- 转发成功后弹“**分享成功**”。

## 8. 私信/聊天（实证）
- 打开：分享面板好友旁“捎句话”，或顶部“消息”→ 会话。
- **输入框是可编辑富文本 div**（class `editor-kit-container`、placeholder“发送消息”），a11y 树不暴露为 textbox；`find("发送消息")` 只返回文本节点。
- 输入方法（JS）：
  ```python
  bu.js("""(() => { const el=[...document.querySelectorAll('.editor-kit-container')].pop(); if(!el)return 'notfound'; el.focus(); document.execCommand('insertText',false,'消息内容'); return el.textContent; })()""")
  ```
- 发送按钮是图标（无文字），用户点“发送”确认；发送后聊天区出现消息与时间（“刚刚”）。

## 9. 通用提醒
- 导航/刷新/弹窗后 ref 失效，重新 snapshot。
- 桌面端“下载 APP / 扫码登录”引导属平台常态。
- 语义定位遇多匹配用 `find(...).first` 或快照核对上下文。
- 未登录/低活跃账号可能有评论/私信风控，以页面实测状态为准，如实汇报。

## 10. 客户端模式（实测 2026-10，抖音 PC 客户端 1920×1080）
- **驱动**：`computer_use_tool(plane="cu")` + `seed_computer_use as cu`，纯坐标+截图 OCR，无 DOM/ref。
- **启动**：`cu.list_apps()` 找含"抖音"应用（形如 `抖音#<hash>`），`cu.launch_app(精确名)`。首次可能报 `ERR_NAME_NOT_RESOLVED` → 点"刷新"重试。
- **登录**：客户端登录态与网页版**独立**。右上"登录"→ 已绑定账号可"一键登录"（实测会转入扫码/验证码/密码界面）；扫码需用户用手机抖音 APP 扫。登录成功标志：顶栏无"登录"按钮。
- **刷流**：主内容区卡片截图 OCR 读取；`cu.scroll(500,500,-5)` 加载更多；未登录时滚动会弹登录窗。
- **操作栏**：视频暂停后显示，**右侧竖直图标**（实测 x≈920，自上而下：点赞/评论/收藏/转发）；坐标随 UI 变化，先截图定位。
- **评论/转发/私信**：入口在右侧操作栏与分享面板，规则同网页版（转发仅互关、私信可送达关注者、对外副作用需用户确认）。
