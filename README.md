# douyin-auto-operator

让豆包在内置浏览器里自动运营抖音的 Agent 技能（Skill）。支持主动刷推荐流、给视频评论、把视频推荐/分享给他人、以及私信送达。

> 本仓库是豆包 Agent 技能（Agent Skill）的发布形式，可直接放入豆包的 skills 目录加载使用。附带网页版与桌面客户端两种执行路径。

## 功能

- **刷流提取（browse）**：主动打开抖音推荐流，滚动加载，提取视频卡片（标题 / 作者 / 时长 / 点赞 / 链接），按用户口径筛选。
- **评论视频（comment）**：登录后进入视频详情，撰写并发布评论。
- **推荐/分享（recommend）**：三条送达路径——
  - A. 抖音内转发给好友（仅限互关好友）
  - B. 复制链接 + 推荐语（可外发）
  - C. 私信发送给关注你的账号（非互关也可送达）
- **私信（dm）**：给指定好友/关注者发私信。

## 安装

1. 将本目录（`douyin-auto-operator`）整个复制到豆包技能的 `.user_skills` 目录下（不同环境的 skills 根目录路径不同，请以豆包工作台实际显示为准）。
2. 依赖浏览器执行器技能 `browser-use-automation`（内置），技能会在运行时读取它。
3. 无需额外依赖或密钥。

## 使用

在豆包对话中直接发起运营需求即可触发本技能，例如：

- “刷一下抖音，整理今天推荐流里最火的几条视频”
- “把这条视频推荐给 XX”（将进入确认流程）
- “给这条视频写条评论”
- “给 XX 发私信，问他……”

涉及**登录、发布评论、转发分享、发私信**等对外操作时，技能会通过用户接管浏览器确认后执行，不会自动外发。

## 执行方式

- **网页版（默认）**：通过内置浏览器自动化（`computer_use_tool` plane="bu"）驱动 `www.douyin.com`，DOM/ref 驱动，操作稳定。
- **桌面客户端（可选）**：当用户明确要求“用客户端抖音”时，通过桌面控制（plane="cu"）驱动抖音 PC 客户端，坐标 + OCR 驱动，操作相对脆弱，以截图实测为准。

## 安全边界

- 评论发布、转发、私信均属对外副作用，一律经用户确认/执行，禁止自动外发、群发、刷屏。
- 不输入、不展示密码 / 验证码 / 支付凭证；登录只走用户扫码。
- 不操作非当前登录账号；不向未经确认的第三方发送。
